## YouTube-specific zones

```
+----------------------------------+
| [duration badge]                 |  bottom-right, ~200x50px
|                                  |
|      SAFE AREA                   |
|                                  |
|                    [timestamp]   |  bottom-right, small
+----------------------------------+
```

Keep the bottom-right corner clear. The duration badge sits on top of
whatever is there.

## The 3-second test

Shrink to 210px wide (a YouTube sidebar thumbnail) and look from arm's
length. At that size only three things survive:

1. A face with a clear expression
2. One large shape
3. One colour accent

If the text is unreadable at that size, it is a texture, not a message.
