# Format Shapes

Beat-by-beat outlines for common formats, with word budgets.

Word budgets assume a narration pace of roughly **140 words per minute** for
conversational delivery, and **160 wpm** for a tight, high-energy read. When a
format has no stated runtime, offer the shape and the budget together so the
user can adjust before you cut.

---

## Short-form vertical (30–60 s)

Budget: 70–140 words. Vertical, muted-first, often watched with sound off.

| Beat | Words | Notes |
|---|---|---|
| Hook | 0–15 | One line. No greeting, no "in this video". Must work with sound off — pair it with an on-screen caption. |
| Context | 0–20 | Only if the viewer cannot infer it. If the hook needs a setup to make sense, the hook is wrong. |
| Payload | 30–70 | The one idea. Concrete, not abstract. |
| Payoff | 15–25 | The thing they came for. |
| CTA | 0–12 | Only if the piece asked for a follow. |

There is no setup section. There is no "and today we're going to look at".

---

## YouTube essay (8–12 min)

Budget: 1100–1700 words.

| Beat | Words | Notes |
|---|---|---|
| Cold open | 60–120 | The most interesting moment, moved to the front. Not a teaser — the real thing. |
| Thesis | 40–80 | What the essay argues, in one paragraph the viewer could repeat. |
| Beat 1 | 250–400 | The first supporting argument. |
| Beat 2 | 250–400 | The second. Escalates. |
| Beat 3 | 250–400 | The third, or the payoff if there were only two. |
| Close | 80–150 | Returns to the cold open with the argument now earned. |

Do not announce the structure ("in part two we'll cover…"). It breaks the
illusion of a person thinking, and it costs words.

## Voiceover / narration

Budget: derived from the runtime. 30 s ≈ 70 words; 60 s ≈ 140; 2 min ≈ 280.

Written to be *heard*, which changes the rules:

- No parentheticals. A voice cannot say "(see chart below)".
- No bullet lists. A voice cannot say "first, second, third" without sounding
  like a form being filled in — write it as sentences.
- No screen-only references. "As you can see here" is meaningless to a listener.
- No numerals where a word is clearer: "twenty-three percent", not "23%".
- Sentences shorter than you think. A listener has no scrollback.

Read the whole thing aloud before delivering it. If you stumble, the
sentence is wrong.

## Product demo script

| Beat | Notes |
|---|---|
| Problem | One line, in the user's words, not the product's. |
| What it does | Two or three sentences. The mechanism, not the marketing. |
| Proof | A concrete result, a number, a before/after. |
| What to do next | One action. If there are two, the second is a different video. |

Every sentence must earn its place in a demo. If a line can be deleted without
the viewer losing the thread, it goes.

## Documentary / brand film

| Beat | Notes |
|---|---|
| Scene 1 | The question, in scene. |
| Scene 2 | The complication. |
| Scene 3 | The turn. |
| Scene 4 | The resolution. |

Each scene states its own visual in one line beneath it. The visual is not
optional — a scene without one is a talking head, and the piece should be
either fewer scenes or a different format.

---

## Talking-head interview

| Beat | Notes |
|---|---|
| Question | As asked. Not rephrased into something more presentable. |
| Answer | The full answer. Do not tighten an answer into a soundbite — the person is speaking, not being quoted. |
| Pull-quote | One sentence from the answer worth using as a caption or a cutaway. |

The most common failure is writing the answer as a soundbite. Interview
answers are messy and qualified; the qualification is usually the interesting
part.
